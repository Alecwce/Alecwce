### 👨‍💻 Sobre Mí

Soy desarrollador de software enfocado en **arquitecturas full-stack modernas**, **automatizaciones autónomas con IA** y **herramientas de escritorio/sistemas**. Me apasiona resolver problemas reales de negocio con código limpio, tipado estricto y excelente experiencia de usuario.

* 🔭 **Trabajando actualmente en:** Sistemas empresariales con arquitecturas basadas en eventos, aplicaciones móviles interactivas y agentes autónomos.
* 🧠 **Intereses:** Inteligencia Artificial aplicada (FSM + LLMs), sistemas distribuidos, optimización de interfaces web y desarrollo de software de escritorio con Rust.
* ⚡ **Enfoque técnico:** Código tipado estricto (TypeScript/Rust/Go), arquitecturas limpias (MVC, ITIL 4) y despliegues serverless modernos.
